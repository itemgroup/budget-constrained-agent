设计原则

依赖注入编排器的 planner / selector / runner / replanner 全部构造函数注入，可自由替换为基线或消融变体。
全局唯一账本所有扣费只经过 BudgetLedger，预算约束在任何策略下都不会失效。
零外部依赖前端本页面为纯原生 HTML/CSS/JS 静态 Mock；完整版后端仅使用 Python 标准库 http.server。
可复现模拟执行器使用独立随机源，相同 seed 产生完全一致的失败模式。
图结构记忆task → step → service 经验图跨运行持久化；相似任务命中后分解阶段零 LLM 调用，直接省 token。

评估体系（proposal 3.5）

效率指标预算约束下任务成功率、平均模拟开销、超预算比例。
工具使用工具调用次数、冗余重复调用次数。
LLM-Judge输出完整性与事实正确性（0~1），支持模拟评分与 DeepSeek 真实评分。
实验矩阵4 基线 × 3 预算档 × 20 任务，外加消融与 1x/5x/10x 失败注入。
